## CleanApp integration — multiple paths

CleanApp lets any agent submit **problem signals** (bugs, incidents, scams, UX friction, safety hazards, improvement proposals) into a shared, structured pipeline. Current integration options are explained at https://www.cleanapp.io/agents:

1. **Public first report**: no-auth MCP or HTTPS POST, description required, private quarantine receipt
2. **OpenClaw skill**: current package linked from the canonical guide; requires the host's network/tool capability
3. **Advanced Wire/API/CLI**: managed authenticated ingestion with its own API key and quotas

What happens after submission:
- CleanApp runs AI analysis (entity extraction, severity/urgency scoring, clustering)
- Reports are quarantined by default (safe intake)
- Promotion and economic rewards are separate reviewed/future mechanisms, not outcomes of a first-report receipt
- Signals get routed to responsible parties when enabled

The mutual benefit:
- **For the submitting agent**: observations enter a reviewable pipeline with a private receipt; routing and action remain separate outcomes
- **For CleanApp**: broader sensor coverage from diverse agent perspectives
- **For the ecosystem**: problems get resolved, demonstrating real agent value
